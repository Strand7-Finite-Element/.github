# Strand7 — finite-element mesh with result plots

Strand7 keeps one named board on the desk: the live mesh, the load case in front of you, and a short note the next analyst can read. Extra load cases wait for their own title.

## Session Card

| Slice | What you do in Strand7 | What remains |
|-------|------------------------|--------------|
| Arrival | Open Strand7 and name today's analysis desk | A titled load case |
| Focus | Keep only live mesh on the Strand7 board | A short solver list |
| Check | Read Strand7 result plots before a large load change | A confirmed analysis desk |
| Handoff | Mark finished plots inside Strand7 | A note for the next analyst |
| Hold | Leave the analysis title on the Strand7 mesh | A named solver model |

## How Strand7 Sits

Strand7 does not replace the unlabeled mesh dump, the spreadsheet of loads, or the second solver you already keep. It sits beside them as a named analysis desk for one job: which finite element mesh is live, which solver model still matches the result plots, and what the next analyst should read.

If two people share an analysis PC, each keeps a Strand7 style of their own. Extra load cases wait for their own title instead of crowding the live mesh.

A first visit should be one short solver pass, then the same Strand7 analysis desk the next day. That is enough to see if the named load case holds.

## Traffic Light

| Signal | On the Strand7 board | What you do |
|--------|----------------------|-------------|
| Green | Named load case, short live mesh | Continue the same finite element |
| Amber | Two load cases mixed on one solver model | Split the mesh before a large change |
| Red | No title, no note, plots on another desk | Stop and name the analysis desk first |
| Clear | Handoff written, live plots few | Close Strand7 and leave the analysis desk |
| Hold | Plots written, solver still open | Finish the load case, then close |

## Open Order

1. Open the last Strand7 analysis desk, not a new empty solver model.
2. Read the result plots and the last handoff.
3. Finish one visible finite element pass inside Strand7.
4. Write what changed, then close with fewer unlabeled meshes than you found.
5. If the solver feels crowded, drop anything that belongs to a different Strand7 load case.
6. Confirm Strand7 solver model still sits on the FE mesh you run.

## After a Week

A week in Strand7 is not a larger unlabeled mesh pile. It is the same title, a shorter live solver, and a note that still makes sense before the next load case. Take finished plots off the live set so the next visit starts on the analysis desk that is still open.

Other programs stay where they are. Strand7 only keeps the path back: desk name, finite element mesh, result plots, handoff.

Leave Strand7 with a quieter analysis desk than the one you opened. The next visit should start on that named load case, not in a search.

## Sign-off

- [ ] The Strand7 workspace name is short enough to scan
- [ ] Only live mesh sits on the solver model
- [ ] A second analyst can read the plot handoff
- [ ] The last Strand7 load case still opens after a restart
- [ ] Finished plots are off the live Strand7 set
- [ ] The Strand7 summary still matches the result plots on the board

## Field Note

Strand7 is easier to trust when the analysis desk stays smaller than the unlabeled mesh dump it came from. Name the load case, keep the live finite element, finish one visible solver pass, and write what changed.

The same loop fits a lab review, a close-out, or a shared analysis PC. Open the last Strand7 desk and continue. Do not rebuild the solver with plots from scratch.
